# Only PyNaCl is bundled — boto3 is already present in the Lambda runtime.
# cffi and pycparser are PyNaCl's transitive dependencies.
#
# Hash-pinned, and the pins are enforced: PyNaCl is the code that verifies
# Discord's Ed25519 signatures, which is the entire authentication boundary of
# this bot. A substituted wheel could silently disable that check and let anyone
# who can find the endpoint URL start and stop the instance. scripts/build_lambda.sh
# passes --require-hashes, so pip refuses to install anything that does not match.
#
# Hashes are for the LAMBDA target (cp312 / manylinux2014_x86_64), not the local
# interpreter. To regenerate after a version bump:
#
#   pip download PyNaCl==<ver> --only-binary=:all: \
#     --platform manylinux2014_x86_64 --implementation cp --python-version 3.12 \
#     -d /tmp/whl && pip hash /tmp/whl/*.whl
